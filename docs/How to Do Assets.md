# إزاي نجهّز كل الـ Assets للعبة

آخر مراجعة: 13 نوفمبر 2026. ده دليل التنفيذ لملف [assets.md](assets.md)، بالمصري، على Windows. المقاسات والألوان اللي تحت اختيارات تصميم للعبة، مش مواصفات معدات NASA حقيقية.

**هنجهّز Assets بس.** مفيش برامج اتثبتت أو موديلات اتعملت بمجرد كتابة الدليل. تنزيل الأدوات أو توصيل MCP مش موافقة على تعديل كود اللعبة.

**تحديث التنفيذ:** اتجهّزت المجلدات، وخريطة أصلية 8K، و8 مؤثرات WAV مبدئية، و37 بطاقة Prompt، وScript لتوليد Batch A في Blender. الصور والموديلات لم تتولد بعد. ابدأ من [Assets Progress.md](Assets%20Progress.md)، وللنسخ المباشر استخدم [Image Prompts.md](Image%20Prompts.md)، ولتشغيل Blender استخدم [Blender Direct Steps.md](Blender%20Direct%20Steps.md). التفاصيل والقيود في [Manifest](../Assets/asset-manifest.md).

## 1. امشي بالطريق ده

| المطلوب | هتعمله بإيه؟ | النتيجة |
| --- | --- | --- |
| المراجع وصور الشخصيات | أداة AI للصور | PNG أو JPG |
| المباني والأرض والعربية | Blender، والأفضل مع MCP عشان أعمل النمذجة معاك | GLB حقيقي ومعاه مصدر Blender |
| الأصوات الاختيارية | Freesound أو تسجيلك، وبعدها Audacity | WAV مع المصدر والرخصة |

صورة مبنى من AI تنفع مرجع؛ مش هتتحول لمبنى تفاعلي بمجرد تسميتها `.glb`. لازم Mesh حقيقي عشان نلف حواليه ونختاره. مش محتاج تتعلم النمذجة كلها: تقدر تعمل الصور وتوصل Blender MCP، وبعدها تبعتلي طلبات التنفيذ الموجودة هنا.

ابدأ بالمراجع وNOVA وAlex، وبعدها Blender/MCP، ثم الأرض وHabitat وSolarArray وLifeSupport. نراجع أول مجموعة قبل باقي المباني. الصوت والشعار والتعبيرات الإضافية يتعملوا بعد الأساسيات.

## 3. صور المراجع باستخدام AI

### طريقة ثابتة لكل صورة

1. افتح أداة الصور، واختار المقاس أو النسبة المطلوبة لو مدعومة.
2. انسخ الـ Prompt. لو الأداة مش بتطلع الدقة المطلوبة، استخدم أعلى دقة بنفس النسبة وسجّل المقاس الفعلي.
3. اعمل نسختين أو 3، واختار الأوضح. حافظ على نفس المرجع والأسلوب في المجموعة كلها.
4. نزّل الصورة الأصلية من الأداة، مش Screenshot، واحفظها بالاسم المطلوب.
5. سجّل الأداة والـ Prompt في Manifest. ما تغيّرش امتداد ملف عشان تدّعي إنه صيغة مختلفة.

## 5. تنزيل Blender على Windows

Blender هو أداة النمذجة اللي هنستخدمها هنا، سواء يدوي أو من خلال MCP. مش محتاج اشتراك أو إضافة مدفوعة لعمل الموديلات الأساسية.

1. افتح [موقع Blender الرسمي](https://www.blender.org/download/).
2. اختار النسخة `Stable` أو `LTS` الموجودة، مش `Experimental` أو `Daily`.
3. اختار `Windows → Installer`. لمعظم أجهزة Intel/AMD اختار `x64`. لو جهازك ARM اختار النسخة المناسبة؛ تعرف من `Settings → System → About → System type`.
4. نزّل ملف `.msi`، افتحه، وكمّل `Next → Install → Finish` حسب المعروض.
5. افتح Blender من Start، وسيب اللغة English عشان أسماء الأزرار تطابق الدليل.
6. افتح `General`، وبعدها `File → Save As`، واحفظ:

```text
C:\Users\mahmo\Downloads\marsastro\Assets\source\mars-assets.blend
```

7. من `Scene Properties → Units` اختار `Metric`، و`Unit Scale = 1`، و`Length = Meters` لو الخيارات ظاهرة.
8. احفظ بـ `Ctrl+S`، واستخدم الملف ده لجلسة المشروع.

صفحة التنزيل كانت بتمنع القراءة الآلية وقت إعداد الدليل؛ عشان كده مش مثبت رقم إصدار أو حجم ممكن يتغير. اختار النسخة المستقرة من الموقع، واختبر توافق الإضافة بعدها. أسماء بعض الأزرار ممكن تختلف حسب إصدارك. [مرجع الإصدارات الرسمي](https://www.blender.org/releases/).

## 6. توصيل Blender MCP

الاختيار المقترح إضافة مجتمعية `MCP for Blender`، مش إضافة رسمية من Blender. اسم الحزمة الحالي `mcp-for-blender` بدل الاسم القديم `blender-mcp`. [مصدر الإضافة](https://github.com/ahujasid/mcp-for-blender).

### 6.1 تثبيت uv

افتح PowerShell ونفّذ:

```powershell
winget install --id=astral-sh.uv -e
```

اقفل PowerShell وافتحه تاني، وجرب:

```powershell
uv --version
uvx --version
```

لازم يظهر رقم إصدار. لو `winget` مش موجود، اتبع طريقة Windows في [تعليمات uv الرسمية](https://docs.astral.sh/uv/getting-started/installation/)، وبعدها افتح Terminal جديد.

### 6.2 تثبيت إضافة Blender

1. احفظ واقفل Blender أثناء تثبيت الإضافة.
2. نفّذ:

```powershell
uvx mcp-for-blender install-addon
```

3. افتح Blender، وبعدها `Edit → Preferences → Add-ons`، وابحث عن `MCP for Blender` وفعّلها.
4. في مساحة العرض اضغط `N`، وافتح تبويب الإضافة؛ لو الخادم مش شغال اضغط `Start MCP Server`.
5. اكتفِ باتصال واحد لنفس الجلسة.

دي خطوات مشروع الإضافة؛ التثبيت والتوافق عندك محتاجين اختبار، ومفيش اتصال Blender شغال عندنا حاليًا.

### 6.3 إعداد Codex

افتح إعداد MCP في التطبيق وأضف خادم لو الاختيار متاح في نسختك. البيانات:

```text
Name: blender
Transport: STDIO
Command: uvx
Arguments: mcp-for-blender
```

لو فيه حقل واحد للأمر، استخدم `uvx mcp-for-blender`. احفظ وأعد تشغيل التطبيق بالكامل. بديل لو Codex CLI متثبت عندك:

```powershell
codex mcp add blender -- uvx mcp-for-blender
codex mcp list
```

لو `codex` مش معروف، استخدم إعداد التطبيق؛ مش لازم تثبّت CLI إضافي. لو التطبيق مش شايف `uvx`، اعرف مكانه:

```powershell
(Get-Command uvx).Source
```

استخدم المسار الناتج كـ Command بدل `uvx`. ما تستبدلش ملف إعداداتك كله لإضافة خادم واحد. [مرجع OpenAI الرسمي لـ MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=app).

### 6.4 اختبار قبل النمذجة

افتح ملف المشروع في Blender، وابعتلي:

```text
اختبر اتصال Blender MCP قراءة فقط: اعرض إصدار Blender، مسار الملف المفتوح، وأسماء Objects. ما تعدّلش أو تمسح حاجة وما تغيّرش كود اللعبة. لو الأدوات مش متاحة قولّي إن الاتصال لسه ما اشتغلش.
```

بعد نجاح الاختبار ابعت:

```text
اعمل Habitat واحد الأول حسب docs/assets.md وdocs/How to Do Assets.md، من خلال Blender MCP، وورّيني Preview قبل باقي الأسرة. احفظ المصادر والتصدير جوّه Assets فقط. ما تغيّرش كود اللعبة وما تشتريش خدمات أو Assets.
```

لو فشل الاتصال: راجع تفعيل الإضافة والخادم ووجود Blender مفتوح، وأعد تشغيل Codex بعد حفظ الإعداد. لو استمر الخطأ ابعت نصّه؛ ما تختارش تعطيل حماية الجهاز أو فتح اتصال خارجي كحل عشوائي.

## 7. خريطة الكوكب

الخريطة المطلوبة ملف مستطيل لسطح المريخ كله، مش صورة كوكب دائري في فضاء. ما نستخدمش AI لتوليدها ونسميها بيانات مقاسة.

1. افتح [Solar System Scope Textures](https://play.solarsystemscope.com/textures/)، ودور على `Mars`.
2. نزّل `Ultra resolution` لو متاحة، واحتفظ بالأصل في `Assets/source`.
3. اتأكد من نسبة الصورة `2:1` وإنها خريطة عالمية `Equirectangular`.
4. لو الأصل `8192×4096`، افتح نسخة في Paint، واختار `Resize → Pixels` مع الحفاظ على النسبة، وخلي العرض `4096` والارتفاع `2048`.
5. صدّر النسخة فعلًا بصيغة JPEG واحفظ `Assets/world/mars-global-color-4k.jpg`.
6. سجّل المصدر والرخصة `CC BY 4.0` والتصغير في Manifest. الموقع بيوضح إن الخرائط معالجة بصريًا وقد تتضمن أجزاء توضيحية؛ ما نسميهاش بيانات NASA خام أو قياس دقيق. [المصدر وشروطه](https://play.solarsystemscope.com/textures/).

لو الدقة أقل، احتفظ بالمقاس الحقيقي واكتبه؛ ما تكبّرش الصورة وتدّعي تفاصيل أصلية أعلى. لو عايز مصدر علمي موثق بدل الخريطة البصرية، اكتب إن اختيار منتج NASA/USGS العالمي متروك لي وقت مرحلة البيانات.

`Assets/world/mars-global-height.png` **اختياري ومؤجّل**: ما تعملهش بـ AI أو من صورة رمادي عشوائية. محتاج منتج ارتفاعات معروف مع الإسقاط وScale/Offset وNoData وعمق البيانات. لو المنتج مش معاك سيبه ناقص بشكل معلن؛ افتتاح اللعبة مش محتاجه.

1. افتح [Poly Haven Textures](https://polyhaven.com/textures)، فئة `Ground & Terrain`.
2. ابحث عن `dry ground` أو `rocky ground` أو `desert sand`.
3. اختار خامة من غير نباتات/طرق، ونزّل نفس الأصل بدقة `2K` مع Base Color وNormal وRoughness لو متاحين.
4. حط الملفات في `Assets/world`، بالأسماء دي حسب وظيفة الصورة:

```text
mars-ground-basecolor.jpg
mars-ground-normal.png
mars-ground-roughness.png
```

5. لو صيغة الأصل مختلفة، احتفظ بالامتداد الحقيقي وسجّل المطابقة بدل تغيير امتداد وهمي.
6. استخدم الخرائط من نفس الأصل ونفس UV؛ ما تخلطهاش مع صورة AI مختلفة وتعتبرهم متطابقين. سجّل Normal هل OpenGL/+Y ولا DirectX/−Y.
7. سجّل المصدر. أصول Poly Haven تحت CC0؛ دي خامة أرضية فنية مش تربة مريخ مقاسة. [الرخصة](https://polyhaven.com/license).

لو خامتك AI، ابدأ بـ Base Color وخامة Matte بسيطة. الـ Normal والـ Roughness اختياريين؛ نقدر نعملهم من مصدر واحد مضبوط في Blender. ما تولّدش صورتين عشوائيتين وتسميهم خرائط تقنية مطابقة.

### 8.3 الأرض التفاعلية

القبول: أرض لها ارتفاعات فعلية ومساحة قاعدة وممر، وتقدر تلف حواليها؛ مش صورة على مستطيل.

## 13. بديل يدوي في Blender

استخدم الطريق ده لو أنت أو مصمم معاك هيعمل النمذجة. لو مش عندك خبرة، الأفضل مرجع AI مع MCP بدل محاولة تخمين كل التفاصيل يدويًا.

1. `File → New → General`، ثم `File → Save As` للمصدر جوّه `Assets/source`.
2. اضبط Metric، واستخدم `Shift+A → Mesh` لإضافة Cube أو Cylinder أو UV Sphere حسب الجسم.
3. افتح لوحة `N → Item` واكتب Dimensions بالأبعاد المطلوبة، بدل تكبير عشوائي.
4. اعمل كل جزء متحرك Object مستقل، وغيّر اسمه من Outliner.
5. للأجزاء الثابتة بعد ضبط المقاس، `Ctrl+A → Rotation & Scale`. راجع Pivot الأجزاء المتحركة قبل التطبيق.
6. حط `3D Cursor` في مركز القاعدة على الأرض، واستخدم `Object → Set Origin → Origin to 3D Cursor` للجسم الرئيسي. للعجلات والأبواب استخدم محور الدوران/المفصلة بدل مركز القاعدة.
7. اعمل Empty كـ Root وسمّيه، واربط الأجزاء تحته مع الاحتفاظ بمواضعها. ما تستخدمش Join للأجزاء اللي هنحركها منفردة.
8. اعمل Materials بسيطة من Material Properties باستخدام Principled BSDF؛ لو فيه صورة استخدم Image Texture في Base Color من Shading.
9. اعمل UV من UV Editing باستخدام Unwrap أو Smart UV Project حسب الشكل، وافحص النتيجة. خامة Procedural معقدة محتاجة Bake قبل Export؛ لو مش متأكد سلّم المصدر عشان أراجعها.
10. فعّل Statistics من Overlays وراجع Triangles؛ خليك قريب من الميزانية المطلوبة من غير إفساد الشكل.
11. اختار الأصل المطلوب بس، من غير كاميرا أو إضاءة أو أجسام اختبار.
12. نفّذ القسم 14.

دي خطوات تأسيس وتصدير؛ مش وصفة تضمن جودة فنية نهائية من أي تجميع Cubes. طلبات MCP فوق بتخليني أنفّذ التفاصيل ونراجعها مع بعض بدل ما تكون أنت مطالب تعرفها كلها.

## 14. التصدير والفحص لكل موديل

### خطوات Export

1. احفظ `.blend` بـ `Ctrl+S`.
2. اختار Root وكل أجزائه بس.
3. افتح `File → Export → glTF 2.0`.
4. اختار `glTF Binary (.glb)` و`Selected Objects`، واتأكد من وجود Meshes وMaterials وUVs.
5. استخدم `Y Up` لو ظاهر. ما تلفش النموذج 90 درجة بشكل عشوائي عشان Blender بيألف بمحاور مختلفة.
6. صدّر Animation لو فيه واحدة مقصودة، من غير اختراع حركة مطلوبة لكل أصل.
7. احفظ بالاسم والمسار المحددين.
8. افتح ملف Blender جديد فاضي، واستورد النتيجة بـ `File → Import → glTF 2.0`.
9. افحص الأجزاء والخامات والمقاس. لو الموديل أبيض، الخامة Procedural ممكن تكون مش مخبوزة أو Texture ناقصة؛ ارجع للمصدر وصلّحها.
10. اطلب مني فحص المحاور واتجاه Rover في عارض اللعبة قبل الاعتماد؛ إعادة الاستيراد في Blender وحدها مش اختبار لمحاور محرك اللعبة.

أسماء بعض الحقول بتختلف حسب الإصدار. المرجع هو صيغة [Khronos glTF](https://www.khronos.org/gltf/)، والمصدر القابل للتعديل يفضل محفوظ حتى بعد نجاح GLB.

### الـ Previews

احفظ لكل موديل لقطة مائلة وأخرى من فوق في `Assets/previews`، مثلًا `habitat-perspective.png` و`habitat-top.png`. مع MCP اطلب Render للصورتين؛ يدويًا ينفع Screenshot نظيفة كمعاينة، بشرط وجود GLB الحقيقي ومصدره.

طلب مراجعة جاهز بعد كل أصل:

```text
افحص المصدر وGLB للأصل الأخير: الأبعاد، Origin، المحاور، أسماء الأجزاء، Textures، عدد Triangles وMaterials، وإمكانية تحديد الجزء المتحرك لوحده. اعمل Preview مائل وآخر من فوق، واكتب المشاكل أو نجاح الفحص في Manifest. ما تعدّلش أصل تاني أو كود اللعبة.
```

خلي المواد قليلة ومشتركة. الهدف للمشهد الظاهر كله حوالي 200 ألف Triangles و150 Draw calls، مش ميزانية مستقلة لكل أصل. الصور العادية 1K–2K؛ ما نحتاجش 4K لكل مسمار. المصدر الكبير مقبول، وهنعمل نسخة Runtime محسّنة بدل ما تقلل جودة الأصول عشوائيًا.

## 15. الأصوات: تنزّل كل ملف وتجهّزه إزاي؟

الصوت اختياري ومش لازم يوقف أول تجربة. ما تشتريش مكتبة أصوات قبل مراجعة الموجود.

### 15.1 التنزيل

1. افتح [Freesound](https://freesound.org/)، واعمل حساب لو طلبه عشان التنزيل.
2. ابحث بكلمات الجدول تحت. اسمع الصوت كامل قبل ما تختاره.
3. افتح صفحة الصوت نفسه واقرأ License. اختار CC0 إن أمكن، أو CC BY وسجّل Credit صاحبه. عشان نسهل إعادة الاستخدام، ما نختارش CC BY-NC أو رخصة مش واضحة للمجموعة دي.
4. نزّل الملف الأصلي في `Assets/source`، وسجّل رابط صفحته واسم صاحبه والرخصة. صفحة البحث مش مصدر كافي لملف محدد.
5. جهّز النسخة النهائية في Audacity بالقسم 15.4. [شرح رخص Freesound](https://freesound.org/help/faq/).

### 15.2 قائمة البحث والنتيجة

كل الأسماء دي تتحفظ جوّه `Assets/audio`:

| الملف | كلمات تكتبها في البحث | تختار إيه؟ |
| --- | --- | --- |
| `space-ambience.wav` | `soft sci fi ambient drone loop` | خلفية هادية 30–60 ثانية من غير كلام أو لحن مشتت؛ مؤثر فني مش تسجيل صوت فراغ الفضاء |
| `base-ambience.wav` | `quiet ventilation hum loop` | تهوية/معدات خفيفة Loop مدته 30–60 ثانية، من غير إنذار أو ضوضاء عالية |
| `ui-select.wav` | `soft interface click` | نقرة هادية 0.1–0.3 ثانية |
| `ui-confirm.wav` | `gentle confirmation beep` | تأكيد مختلف عن النقرة، 0.2–0.5 ثانية |
| `mission-warning.wav` | `gentle alert notification` | تنبيه بسيط 0.5–1 ثانية، مش Siren مخيفة |
| `radio-message.wav` | `radio message notification` | إشارة وصول رسالة 0.5–1.5 ثانية، من غير كلام غير مطلوب |
| `rover-loop.wav` | `small electric motor loop` | موتور هادي قابل للتكرار، 2–5 ثواني، من غير صوت مرور أو Doppler متسجل فيه |
| `discovery.wav` | `short discovery chime` | نغمة اكتشاف لطيفة، 1–2 ثانية |

دي كلمات بحث ومواصفات، مش ضمان إن أول نتيجة مناسبة أو مرخصة. لو أداة AI عندك بتولد صوت، ينفع تستخدم نفس الوصف والمدد مع طلب «من غير كلام أو موسيقى مقتبسة»، بس سجّل الأداة وشروطها برضه.

### 15.3 تنزيل Audacity

1. افتح [التنزيل الرسمي لـ Windows](https://www.audacityteam.org/download/windows/).
2. اختار `x86_64 MSI installer` لأجهزة Intel/AMD، أو ARM64 لو جهازك من النوع ده.
3. ثبّته وافتحه. قص الملفات وتصدير WAV مش محتاج اشتراك أو Plugins مدفوعة.

### 15.4 تجهيز كل صوت

1. افتح الملف من `File → Open` في Audacity.
2. اسمعه، وحدد الجزء المطلوب. قص الصمت والزيادات مع الاحتفاظ بالأصل.
3. للمؤثر القصير: لو فيه Click بسبب القص، استخدم Fade قصير عند الطرف المحتاج معالجة. للخلفية اختار أصل Seamless loop من البداية بدل ما تقص مكان عشوائي.
4. اسمع الـ Loop متكرر 3 مرات. لو الوصلة بتقطع، اختار ملف أنضف أو ابعتلي الأصل عشان أجهز Crossfade مناسب. Fade In/Out للصوت كله مش بيضمن Loop؛ ممكن يعمل هبوط في كل لفة.
5. لو محتاج تسوية القمم، اختار `Effect → Volume and compression → Normalize` وخلي القمة مثلًا `−3 dB` كهدف تجهيز للمشروع. ده مش معناه نخلي كل الخلفيات عالية؛ المزج النهائي في اللعبة. [مرجع Normalize](https://www.audacityteam.org/manual/effects/volume-and-compression/normalize/).
6. `File → Export Audio` أو `Ctrl+Shift+E`.
7. اختار الصوت الكامل أو الجزء المختار حسب اللي جهّزته، والحفظ المحلي على جهازك.
8. اختار `WAV`، و`48000 Hz`، و`16-bit PCM` أو `24-bit PCM` لو متاح. Mono للمؤثرات اللي مش محتاجة اتجاه، وStereo للخلفية لو أصلها Stereo.
9. احفظ بالاسم المكتوب في الجدول، وافتح WAV الناتج واسمعه. ملف مشروع Audacity مش هو الصوت النهائي حتى لو غيّرت اسمه.
10. سجّل مدة Loop وحدوده لو الأصل فيه مقدمة أو نهاية. [تعليمات Export الرسمية](https://www.audacityteam.org/manual/getting-started/export-your-audio/).

### 15.5 Voice للشخصيات

1. استنى اعتماد النص واللغة قبل التسجيل؛ القصة لسه مرتبطة بمراجعة التسلسل.
2. سجّل كل سطر في ملف منفصل في أوضة هادية. اعمل تجربة سطر واحد الأول، بصوت واضح وهادي ومشجع.
3. استخدم صوتك أو مؤدّي موافق على استخدام صوته. لو AI voice، اختار صوت مسموح للمشروع، من غير تقليد شخص معروف من غير إذن.
4. احفظ حسب Story node، مثلًا `Assets/audio/voice/alex-power-01.wav`، ومعاه النص المكتوب واللغة وبيانات الإذن عشان Captions تطابقه.
5. صدّر Mono WAV بخطوات القسم 15.4. سيب النسخة الأصلية من غير موسيقى أو Radio effect دائم؛ نضيف التأثير وقت المزج لو مناسب.

## 16. الشعار الاختياري

النتيجة: `Assets/branding/logo.png`، ومعاه `Assets/branding/logo.svg` لو فيه Vector حقيقي.

```text
اعمل فكرة شعار أصلية للعبة تعليمية Mars Mission Commander، رمز بسيط يجمع المريخ والاستكشاف والقيادة بشكل واضح، صدئي وأخضر غامق وأبيض دافي، Flat vector style، مقروء وهو صغير. من غير تقليد NASA أو Google أو أي لعبة. الرمز لوحده على Transparent background، ومن غير حروف مولدة غلط. الاسم نقدر نضيفه بعدين بخط مرخص.
```

1. نزّل PNG شفافة بدقة 1024×1024 أو أعلى.
2. لو أداة تصميم بتصدّر Vector، صدّر SVG كمان. لو معاك PNG بس، سلّمه واكتب SVG ناقص.
3. تغيير امتداد PNG إلى SVG مش تحويل لـ Vector. ممكن نعمل Tracing وتنضيف بعدين، لكن ما ندّعيش إن ده حصل من غير فحص.
4. لو هتضيف الاسم بخط، سجّل اسم Font ورخصته. ما تعتمدش كتابة AI المشوهة كشعار نهائي.
