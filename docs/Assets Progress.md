# اللي اتجهّز واللي مطلوب منك دلوقتي

تاريخ التحديث: 13 نوفمبر 2026. الشغل هنا في `Assets` و`docs` فقط، من غير تعديل كود اللعبة أو إعداداتها.

## اتعمل بالفعل

- إنشاء مجلدات التسليم، مع الحفاظ على المجلدات الموجودة.
- تنزيل خريطة المريخ الأصلية بدقة 8192×4096 من Solar System Scope، وفحص الملف والصورة وتسجيل المصدر والرخصة في [Manifest](../Assets/asset-manifest.md). تجهيز نسخة 4K لسه متبقي.
- إنشاء 8 ملفات WAV أصلية مبدئية في [Assets/audio](../Assets/audio)، مع Script يعيد توليدها وتقرير تقني. الصيغة والمدة والقنوات والقمم اتفحصت، لكن لازم مراجعة بالسماع قبل الاعتماد.
- تجهيز [37 Prompt](Image%20Prompts.md) للصق مباشرة في أداة الصور. كل واحد له TXT مستقل في `Assets/references/prompts`.
- تجهيز Script لتوليد نماذج Batch A مبدئية في Blender، وتعليمات تشغيل مباشرة من غير MCP.

## اللي لسه ما اتعملش

- الصور نفسها لم تتولد؛ المطلوب منك تستخدم الـ Prompts بأداة الصور اللي عندك.
- Blender غير متثبت هنا ومفيش اتصال Blender محلي ظاهر؛ الـ Script اتفحص نحويًا فقط، ومفيش GLB/Render خرج منه لسه.
- النماذج المبدئية مش بديل المراجعة الفنية، ومش اعتماد لشكل اللعبة النهائي.
- مفيش تثبيت برامج أو إضافات أو دمج أصول في التطبيق أو نشر.

## امشي بالترتيب ده

1. افتح [Image Prompts.md](Image%20Prompts.md). اعمل أولًا الصور الأساسية الموسومة Batch A: المراجع الثلاثة وNOVA وAlex وخامة الأرض. مراجع المباني Concept اختيارية لو هتساعدك تحدد الشكل.
2. احفظ كل صورة في المسار المكتوب. الملفات النصية مش صور، وصور الـ Concept مش GLB.
3. افتح [Blender Direct Steps.md](Blender%20Direct%20Steps.md)، ونفّذ Habitat فقط الأول. لو هتوصل MCP بدل الـ Script، استخدم إعداد القسم 6 من [الدليل](How%20to%20Do%20Assets.md).
4. ابعتلي إن الملفات/الـ Previews موجودة. هنراجع الشكل قبل تشغيل باقي المجموعة.
5. اسمع مؤثرات `Assets/audio` واكتب اللي عجبك واللي عايزه يتغير. مفيش ضرورة تنزّل أصوات تانية إلا لو المبدئية مش مناسبة.

لو مش عايز تتعامل مع Script، ممكن تثبّت Blender وتوصل MCP وتخليني أتعامل مع النمذجة بعد اختبار الاتصال. إعدادات تثبيت الأدوات لسه قرارات بتنفيذك، مش عمليات اتعملت في الخلفية.
